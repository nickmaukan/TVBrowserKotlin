# 📺 TV Browser Kotlin - Android TV

Navegador optimizado para Android TV con control remoto D-pad.

## Características

- 🎮 **Control D-pad** - Navegación completa con control remoto
- 🌐 **WebView** - Navegación web completa
- 🎬 **Video Player** - Reproducción de videos
- 🌙 **Tema oscuro** - Interfaz elegante

## Requisitos

- Android 5.0+ (API 21)
- Android TV o box compatible

## Build

```bash
# Configurar SDK
echo "sdk.dir=/path/to/android/sdk" > local.properties

# Build
./gradlew assembleDebug
```

## APK

`app/build/outputs/apk/debug/app-debug.apk`
